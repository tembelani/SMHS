System Name: SHMSApp (Student Housing Management System)

Purpose of this Application: 
- Management of Students to their assigned rental rooms
- Keep the records of the contracts of the students occupying the building
- Create new applications for students that apply to stay in the building
- Monitor rooms occupied by students. 

Tools used: MySQL, Java and JDBC which will need to be installed before the use of the SHMS App.

Key features:
- View Students.
- Available rooms.
- Add contracts dynamically,
- SQL constraint prevent double-bookings

How to run the application:
- Run MySQL server and execute schema SQL.
- Compile Java code (using Terminal or GitBash): javac StudentHousingApp.java
java StudentHousingApp
- Select the menu that you want and interact via console.
